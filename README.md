# Новогодний барометр Catering Heroes

Отдельная анкета и пульт ведущего. Ответы хранятся в отдельной Google Таблице.

## Файлы
- `index.html` — участники, 9 вопросов и необязательный комментарий.
- `dashboard.html` — диаграммы, QR-код, режим экрана зала и выгрузка CSV.
- `Code.gs` — код Apps Script, привязанный к таблице.
- `config.js` — публичный адрес развёрнутого Apps Script. Ключ ведущего сюда не добавлять.

## Подключение
1. В новой Google Таблице открыть «Расширения → Apps Script».
2. Заменить код содержимым `Code.gs`, сохранить и выполнить `setup` один раз. Разрешить работу с таблицей.
3. В журнале выполнения сохранить ключ ведущего. Он также находится в свойствах скрипта `ADMIN_TOKEN`.
4. «Начать развертывание → Новое развертывание → Веб-приложение». Выполнять от имени владельца; доступ для всех, чтобы участникам не нужен был аккаунт Google.
5. Адрес `/exec` записать в `config.js` как `window.SURVEY_ENDPOINT`.
6. Разместить HTML, CSS и JS файлы в GitHub Pages. Открыть `index.html` участникам, `dashboard.html` ведущему.

POST отправляет ответ, а отдельная квитанция подтверждает запись. Повторная отправка с этого устройства обновляет строку по ID, не добавляя голос. Один ответ от компании обеспечивается организационно; строгой идентификации компаний в этой версии нет.

Публичная сводка не содержит имён, контактов и комментариев. Ключ ведущего открывает комментарии, хранится только в текущей сессии браузера. Для экрана зала есть режим без комментариев. Запись в Google Таблицу защищена блокировкой от одновременных обновлений.

Сводка обновляется раз в 5 секунд при открытом дашборде. Доступность зависит от сети и квот Apps Script; перед мероприятием проверить нагрузку на ожидаемом числе устройств.

Это опрос участников мероприятия, не репрезентативная оценка всего рынка. Средние значения рассчитываются с одинаковым весом каждой компании; дополнительно показана медиана. Рост чека — среднее индивидуальных изменений. Указывать дату, географию и число содержательных ответов по каждому вопросу.
