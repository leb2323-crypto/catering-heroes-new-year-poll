# Новогодний барометр Catering Heroes

Анкета из семи вопросов. На первом экране QR-код на саму страницу и кнопка «Начать опрос».

1. Регион.
2. Средний чек на гостя в декабре: три отдельных поля — банкет, фуршет, событийная доставка. Пустое поле означает отсутствие данных.
3. Изменение декабрьского чека за год, в процентах.
4. До двух причин изменения чека, с обязательным пояснением при выборе «Другое».
5. Изменения декабрьских запросов корпоративных клиентов — свободный ответ.
6. Изменения декабрьских запросов частных гостей — свободный ответ.
7. Изменение объёма алкоголя на гостя в декабре, без детализации по напиткам.

HTML, JS и CSS опубликованы через GitHub Pages. Приём ответов — Google Apps Script в отдельной Google Таблице. Новая схема хранится на вкладке «Ответы v2»; старая вкладка не изменяется.

## Подключение и обновление
В редакторе привязанного Apps Script сохранить `Code.gs`, выполнить `setupV2` один раз и обновить существующее развёртывание новой версией. Существующие настройки доступа сохраняются. Адрес `/exec` находится в `config.js`.

`index.html` — анкета. `dashboard.html` — результаты, QR-код, переключение вопросов и CSV. Средние чеки показываются отдельно для каждого формата. Свободные ответы отображаются текстом без имени и контакта; на сайте нет сбора персональных контактов. В интерфейсе показаны последние 100 текстовых ответов, все ответы хранятся в таблице.

Ответ записывается через POST. Квитанция подтверждает фактическое сохранение. Повторная отправка с этого устройства обновляет строку, а не добавляет голос. Один ответ от компании обеспечивается организационно. Черновик хранится на устройстве, версия анкеты имеет отдельный ключ черновика.

Дашборд обновляется каждые пять секунд. Это опрос участников мероприятия, а не репрезентативная оценка всего рынка. При публикации указывать дату, географию, число компаний и число ответов по каждому показателю.
